Research participation

When your course server runs a study, DLC asks once, on the first start, whether your usage may be recorded for research. Declining keeps every feature working and records nothing. To withdraw later, contact the research team named on the information sheet.

Official tests

Register the instructor-issued testcase for any file. When a student's testcase matches (comments and spacing ignored), Mode B treats its rows as ground truth: a disagreement means the circuit is wrong, never the test. Stored locally; works for any lab, no manifest needed.

Built-in defaults are view-only — the only way to raise a default's standard is Adopt into official tests after a Coverage Coach run ends all set. Your own labs' tests can be added and edited freely below (content must be valid Digital test format). If existing tests cover everything, mode B will produce nothing.

Configuring new labs (instructors)

A manifest is only needed when a lab requires semantic interpretation — opcode / RISC-V standard decode, or display-digit classes. The shipped defaults already cover the current course labs. Professors adapt DLC to their own labs by forking the repo and adding a small manifest (a json naming the lab's test categories) plus the official test sets.
